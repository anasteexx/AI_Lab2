
# Лабораторна робота №2

**Дисципліна:** Основи штучного інтелекту

**Тема:** Моделювання нейронних мереж. Перцептрон Розенблата. Мережі Хопфілда і Хемінга.

## Опис проєкту

Реалізовано систему розпізнавання графічних образів із використанням трьох типів нейронних мереж: перцептрона Розенблата, мережі Хопфілда та мережі Хемінга.

Програму розроблено мовою Python із графічним інтерфейсом Tkinter. Для обробки BMP-зображень використано Pillow.

## Завдання 1. Перцептрон Розенблата

- Розпізнавання образів двох класів.
- Побудова абсолютних і нормованих векторів ознак.
- Ініціалізація та коригування вагових коефіцієнтів.
- Навчання з учителем.
- Оцінювання збіжності процесу навчання.

## Завдання 2. Мережі Хопфілда та Хемінга

### Мережа Хопфілда
- Розпізнавання образів трьох класів.
- Формування біполярних векторів ознак.
- Обчислення матриці ваг.
- Ітераційне відновлення образів.

### Мережа Хемінга
- Розпізнавання образів трьох класів.
- Обчислення вагових коефіцієнтів.
- Використання гальмівних зв'язків.
- Визначення найбільш схожого еталона.

## Використані технології

- Python
- Tkinter
- Pillow
- unittest

## Структура проєкту

- `common/` — обробка зображень і побудова векторів ознак.
- `task_1/` — перцептрон Розенблата.
- `task_2/` — мережі Хопфілда та Хемінга.
- `main.py` — запуск графічного інтерфейсу.

Кожне завдання містить програмний код, README.md та PDF зі скриншотами результатів.

## Встановлення та запуск

Встановити залежності:

    python -m pip install -r requirements.txt

Запустити програму:

    python main.py

## Тестування

Запуск усіх модульних тестів:

    python -m unittest discover -v

## Результати

Перцептрон Розенблата успішно навчено розпізнавати два класи. Навчання досягло збіжності за 15 епох.

Мережа Хопфілда відновила змінений образ цифри 2 за 2 ітерації.

Мережа Хемінга правильно класифікувала змінену цифру 2 за 7 ітерацій.

Усі три мережі успішно пройшли проведені перевірки.
