
# Завдання 1. Перцептрон Розенблата

## Опис
Реалізовано систему розпізнавання графічних образів двох класів на основі одношарового перцептрона Розенблата.

## Реалізація
- Завантаження та відображення BMP-зображень.
- Побудова абсолютних і нормованих векторів із 25 ознак.
- Ініціалізація вагових коефіцієнтів і порога активації.
- Класифікація образів із вихідними значеннями -1 та 1.
- Навчання з учителем і коригування ваг.
- Відображення стану перцептрона після навчання.
- Оцінювання збіжності за кількістю помилок на кожній епосі.

## Файли
- `perceptron.py` — алгоритм перцептрона Розенблата.
- `perceptron_ui.py` — графічний інтерфейс.
- `test_perceptron.py` — модульні тести.
- `../common/features.py` — обчислення векторів ознак.

## Результати
Перцептрон навчено розпізнавати цифри 0 та 1.

Навчання завершилося за 15 епох. На останній епосі кількість помилок дорівнювала нулю.

Після навчання:
- Цифра 0 розпізнана як клас -1.
- Цифра 1 розпізнана як клас 1.

## Запуск
Із кореневої папки проєкту:

    python main.py

Тестування:

    python -m unittest task_1.test_perceptron -v
