
# Завдання 2. Нейронні мережі Хопфілда та Хемінга

## Опис

Реалізовано систему розпізнавання графічних образів трьох класів із використанням нейронних мереж Хопфілда та Хемінга.

## Реалізація

### Мережа Хопфілда
- Завантаження трьох еталонних BMP-зображень.
- Побудова абсолютних і біполярних векторів із 25 ознак.
- Формування матриці ваг розміром 25×25.
- Ітераційне оновлення станів нейронів до стабілізації.
- Відновлення образів за асоціативним принципом.
- Відображення результатів класифікації та історії ітерацій.

### Мережа Хемінга
- Завантаження трьох еталонних зображень.
- Побудова абсолютних, нормованих і біполярних векторів ознак.
- Обчислення вагових коефіцієнтів першого шару.
- Використання гальмівних зв'язків другого шару.
- Ітераційне визначення нейрона-переможця.
- Відображення активностей нейронів, відстаней Хемінга та результатів класифікації.

## Файли

- `hopfield.py` — алгоритм мережі Хопфілда.
- `hopfield_ui.py` — графічний інтерфейс мережі Хопфілда.
- `test_hopfield.py` — модульні тести.
- `hamming.py` — алгоритм мережі Хемінга.
- `hamming_ui.py` — графічний інтерфейс мережі Хемінга.
- `test_hamming.py` — модульні тести.
- `../common/features.py` — обробка зображень та побудова векторів.

## Результати

Обидві мережі протестовано на зображеннях цифр 0, 1, 2.

Мережа Хопфілда відновила змінений образ цифри 2 за 2 ітерації. Відстань між вихідним вектором і еталоном класу 2 дорівнювала нулю.

Мережа Хемінга визначила змінену цифру 2 за 7 ітерацій. Відстань Хемінга до еталона класу 2 становила 6.

Обидві мережі правильно розпізнали перевірені образи.

## Запуск

Із кореневої директорії проєкту:

    python main.py

Тестування:

    python -m unittest task_2.test_hopfield task_2.test_hamming -v
